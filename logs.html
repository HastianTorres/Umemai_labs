LOG / 003RECONSTRUÇÃO2026

Reconstruindo o laboratório

Uma nova versão não precisa apagar a história da anterior.

A Umemai Labs começou como um site simples, feito com HTML, CSS e JavaScript. Essa primeira etapa ajudou a praticar estrutura, estilização e publicação. A reconstrução organiza melhor a experiência, a navegação e a manutenção.

Decisões desta versão

  • Priorizar uma arquitetura estática, leve e compatível com GitHub Pages.
  • Manter a identidade em preto e vermelho, com contraste consistente.
  • Diferenciar ideias, protótipos e entregas finalizadas.
  • Documentar como executar, testar e publicar o site.

Próximo passo: validar em diferentes telas, revisar conteúdo e só então promover a versão para a branch principal.

LOG / 002PUBLICAÇÃO2026

Publicar sem complicar

Uma boa infraestrutura resolve o problema sem criar outros.

Para um laboratório pessoal, um site estático é uma escolha eficiente. HTML, CSS, JavaScript e SVG podem ser publicados pelo GitHub Pages sem manter um servidor próprio. Isso reduz custos e simplifica o deploy.

Quando surgirem necessidades como autenticação, dados privados ou formulários com envio real, a arquitetura deverá ser revista. Não é necessário adicionar backend antes de existir uma necessidade concreta.

LOG / 001PRIMEIRA VERSÃO2026

A primeira versão

Começar pequeno também é começar de verdade.

A primeira versão foi um exercício de transformar aprendizado em prática com tecnologias fundamentais da web. O foco foi montar uma página, aplicar estilos próprios e entender como colocar o projeto online.

O próximo capítulo é evoluir sem perder essa intenção: aprender construindo e compartilhar o caminho sempre que fizer sentido.
